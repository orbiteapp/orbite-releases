# Orbite — téléchargements Windows

Ce dépôt est réservé à la distribution des installateurs Windows x64 et des mises à jour de l’application Orbite, une application de mathématiques pour le lycée général et technologique.

Les programmes sont proposés dans la rubrique **Releases**. Choisissez l’installateur `Orbite-Installation-<version>-x64.exe` de la version souhaitée.

Les cours, exercices, évaluations, corrections, comptes et résultats des élèves ne sont pas hébergés dans ce dépôt. Les contenus pédagogiques restent distribués par le service Google privé d’Orbite.

Orbite conserve sur l’ordinateur les contenus téléchargés pour permettre le travail hors connexion. L’inscription initiale et les échanges avec les services en ligne nécessitent une connexion Internet.

Les versions publiées sont des versions de travail destinées aux essais du projet.
